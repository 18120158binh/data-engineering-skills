# Sources

- [superpowers](https://github.com/obra/superpowers), by Jesse Vincent and Prime Radiant (MIT). The default provider of engineering method: brainstorming, planning, test-first, debugging, verification, review, and finishing a branch.
- [pstack](https://github.com/cursor/plugins/tree/main/pstack), by Lauren Tan (MIT). The default provider of investigation, execution playbooks, and orchestration. Standalone mirror: [backnotprop/pstack](https://github.com/backnotprop/pstack).
- [rea](https://github.com/morluto/rea) `reverse-engineer-anything` (MIT). The idea that each conclusion carries its evidence, how sure it is, and what is still unresolved, used in the decision trail.

This skill names their skills and playbooks and does not restate their content. If a name here no longer matches the installed version, follow the installed skill and fix this file.
